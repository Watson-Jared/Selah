# Selah

An Android app that blocks distracting apps until you spend a moment in Scripture.
Choose how you unlock: type the verse, fill in the blank, or answer a question about it.

**Status:** In development (Milestone 1: verse data)
**Stack:** Kotlin, Jetpack Compose, Room
